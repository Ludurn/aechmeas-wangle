# Aechmea's Wangle

A terminal-based manager for creating and organizing custom tabletop role-playing game (TTRPG) character sheets.

> The project is under active development. Features and interfaces may change over time.

## Project Status

The project is currently in pre-alpha development. The first planned release is v0.1.0.

## Built With
- [Rust](https://rust-lang.org/)
- [Ratatui](https://ratatui.rs/)

## Roadmap

### Alpha Release (v0.1.0)

- [ ] Develop a home screen for viewing and managing existing character sheets
- [ ] Implement a step-by-step workflow for creating reusable character sheet models
- [ ] Enable the creation of new character sheets from a selected model

### Beta Release (v0.2.0)

- [ ] Expand the available widgets and improve the model creation experience
- [ ] Allow users to assign a profile picture to each character sheet

### Stable Release (v1.0.0)

- [ ] Add support for exporting character sheets and models
